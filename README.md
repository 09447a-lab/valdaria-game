# صعود الفهد — ملف سري
## Valdaria: Rise of the Common Man

لعبة استراتيجية سياسية-عربية (HTML/CSS/JS pure).

## التشغيل

### الطريقة 1: فتح مباشر
افتح `index.html` في المتصفح.

### الطريقة 2: سيرفر محلي
```bash
cd /workspace/game
python3 -m http.server 8000
# ثم افتح http://localhost:8000
```

## المميزات

- **بطل مدني**: طالب جامعي في الجمهورية الخيالية "فالداريا".
- **نظام خريطة SVG** تفاعلية (zoom/pan) بـ 7 مدن + 12 قرية + 4 مطارات + 8 مراكز شرطة + قلعة محصنة.
- **نظام اقتصاد**: 6 مصادر دخل قابلة للتدمير (متجر، مصنع، مزرعة، شركة نقل، عقار، مركز تجاري).
- **نظام أكل وصحة شامل**: كل شخصية تموت إذا وصل جوعها إلى الصفر.
- **أسواق شاملة**: ملابس، أكل، سيارات، أسلحة.
- **نظام تهريب أسلحة محظورة** بـ 3 مستويات صعوبة (المخاطرة على المشتري).
- **معارك تكتيكية** مع 6 استراتيجيات و 3 مراحل تخفيف ذخيرة.
  - المرحلة 3: ميزة استنزاف ذخيرة العدو مقابل ضعف قوة جنودك.
- **تحصينات** بـ 5 أنواع وأوقات بناء واقعية (5 ثوانٍ إلى دقيقتين).
- **AI بثلاث مستويات صعوبة** (سهل/متوسط/صعب).
- **صفحة "الملف السري"** بستايل أرشيف استخباراتي قديم.

## طريقة اللعب

1. **شاشة البداية**: اختر اسم + مستوى صعوبة، ثم ابدأ.
2. **الصفحة الرئيسية**: ملخص وضعك.
3. **الاقتصاد**: ابنِ مصادر دخل (ابدأ بمتجر 5,000).
4. **الأسواق**: اشترِ طعام لجنودك (إلّا بيوم 7,500).
5. **الخريطة**: تصفّح المواقع.
6. **التحصينات**: حصّن مدنك قبل أي هجوم.
7. **المعارك**: اختر استراتيجية ومرحلة ذخيرة.
8. **القائمة → الجولة التالية**: تقدّم الزمن، يحين دور AI.
9. **الملف السري**: اقرأ ملف فيلانت لمعرفة أدلة إدانته.

## التوازن

- 5 جنود بداية + 20,000 ₱.
- جندي واحد يأكل 20 وحدة جوع/جولة.
- الجيش يحتاج 7,500 ₱/جولة للطعام إذا كان لديك 50 جندي.
- مصادر دخل صغيرة (متجر) تعطيك 800/جولة، لن يكفي مع جيش كبير.
- خطّط لبناء عدة مصادر قبل التوسيع.

## ملاحظات

- **نسخة تجريبية MVP**. لا يوجد نظام حفظ للوقت/التاريخ، فقط عدد الجولات.
- المحفوظات في localStorage. تنظيف الكاش يحذفها.
- كل النصوص عربية (RTL).
- بدون backend، كله client-side.
